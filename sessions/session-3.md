# Сессия 3 — 25 августа 2026

**Цель сессии.** Собрать материал для исследования по рекуррентным платежам на EVM, разделив его на четыре независимых блока, и на этом же материале доделать замер: четыре субагента параллельно против последовательного прогона тех же четырех блоков, сделанного раньше в чистой сессии.

**Что сделано.**

- Агент прочитал AGENTS.md и запустил четыре субагента одним сообщением, параллельно. Каждому — своя зона и прямой запрет на чужую: providers.md, allowance.md, trigger.md, failures.md.
- Всем четырем переданы одинаковые правила работы: искать в сети, а не писать по памяти; каждый содержательный тезис — со ссылкой на источник в тексте; нет надежного источника — писать "не подтверждено" вместо правдоподобного текста; писать только в свой файл.
- Закрыты для всех четверых: SPEC.md, SPEC-ANSWERS.md, AGENTS.md, CLAUDE.md, REPORT-NOTES.md, каталоги src/, test/, script/, web/, data/, evidence/, sessions/ и файлы research/seq-*.md первого прогона.
- Получены четыре файла, 2622 строки, 225 171 байт, 329 ссылок на источники: providers.md (443 строки, 58 ссылок), allowance.md (690, 38), trigger.md (786, 111), failures.md (703, 122).
- Результаты в один документ не сводились — это было условием задания.
- Заполнен evidence/measurement.md: показатели второго прогона и раздел "Где оказалась разница".
- Проверено по git status, что изменений вне research/ и evidence/ нет: спецификация, код и фронт не тронуты.
- Удалены .gitkeep из evidence/ и research/ — каталоги больше не пустые.

**Что не получилось.**

- Параллельный прогон уперся в лимит сессии посреди работы. Один субагент
  упал сразу после записи файла и не отдал резюме. Файл при этом полный,
  восстанавливать резюме не стал — цифры есть в самом документе.
- Сайты Loop Crypto не открылись ни через инструмент загрузки, ни через
  curl. Два агента независимо оговорили это в своих файлах и привели
  содержимое по цитатам из поисковой выдачи, вместо того чтобы дописать
  правдоподобное.
- Каталог evidence/ агент счел отсутствующим, хотя он был создан
  в первый вечер: единственный файл в нем был скрытым, и обычный листинг
  его не показал.

**Размышления.**

- Замер сделан честно: последовательный прогон шел первым, в чистой
  сессии, параллельный — тоже в чистой. Иначе цифры по контексту
  сравнивать было бы нельзя.
- Субагентам запрещено читать файлы последовательного прогона. Без этого
  запрета замер превратился бы в мусор: второй прогон переписывал бы
  первый вместо самостоятельного поиска.
- Правило "нет источника — пиши не подтверждено" сработало на всех четырех
  блоках. Самая ценная находка исследования именно такая: отраслевого
  стандарта обработки сбоев в on-chain биллинге не существует, все решения
  проприетарные и вынесены за пределы цепочки.
- Спецификация была закрыта для всех агентов, и ни один в нее не полез.
  Это принципиально: контракт еще не написан, а спека уже зафиксирована
  вместе с контрольными значениями.

**Время.** ~13 минут работы субагентов; по календарю ~3 ч 55 мин с паузой на сброс лимита сессии.
