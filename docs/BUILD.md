# Сборка research.pdf

Верстку держит Paged.js (`vendor/paged.polyfill.min.js`), печатает headless Chrome; инструмент печати ставится одной командой и в репозиторий не кладется: `npm i --no-save puppeteer-core`.

Печатать нужно не раньше, чем разбивка закончится: открыть `research.html`, дождаться, пока число `.pagedjs_page` перестанет расти, и только тогда вызвать `page.pdf({ printBackground: true, preferCSSPageSize: true })` — иначе Chrome выдает PDF на одну страницу.

Номера полос в оглавлении проставляются вторым проходом: `target-counter` считается до того, как правила переносов сдвинут разделы, поэтому фактические страницы снимаются с готового PDF и записываются в `data-page` ссылок оглавления (и в `.pages.json`), после чего PDF печатается повторно.
